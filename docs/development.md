# 開発者向けの手引き

開発者向けの内容を置く。利用者向けの導入と使い方は [README](../README.md) にある。

## 動作解説ページ（docs/organize-ask/）

`organize` と `ask` が、実際に何を読み、何を実行し、何を標準出力に返すかを示すページ。Claude Code の Artifact として公開する。

| ファイル | 内容 |
|---|---|
| `docs/organize-ask/page.html` | 文章のテンプレート（CSS・解説・表・カード）。写しは書かず、`{{名前}}` で埋める |
| `docs/organize-ask/build.py` | 生成スクリプト（標準ライブラリのみ） |

### 生成する

```
python docs/organize-ask/build.py --out <リポジトリの外のフォルダ>
```

- 出力は、`page.html`（Artifact に公開する形）と `page.local.html`（ブラウザで開く用に、最小の枠を付けたもの）。
- 出力先がリポジトリの中なら、止まる。
- 実行のたびに、次を行う。
  1. 一時フォルダにデモ Vault を作り、`vault_inbox.py` を手順の順に実行して、標準出力・終了コードを採取する。
  2. 全文・ファイルの大きさ・版・行番号（構文解析）を、リポジトリから読む。
  3. 採取した出力のパスと乱数を、印（`<P>`・`<D>`・`<起動フォルダ>`・`<○○のid>`・`<pid>` など）に置き換える。
  4. `page.html` の `{{名前}}` を埋める。一時フォルダのパス・ユーザー名が残っていれば、止まる。

### `{{名前}}` の種類

| 書式 | 展開されるもの |
|---|---|
| `{{file:<パス>}}`・`{{fold:<パス>}}` | ファイルの全文（`fold` は折りたたみ） |
| `{{size:<パス>}}`・`{{lines:<パス>}}` | 大きさ・行数 |
| `{{ln:<パス>:<関数名>}}` | 関数・クラスの定義行 |
| `{{const:<パス>:<定数名>}}`・`{{default:<パス>:<関数名>:<引数名>}}` | 定数・引数の既定値 |
| `{{run:<キー>}}` | デモで採取したコマンド・終了コード・標準出力（引数ファイルがあれば「書く」も） |
| `{{vfile:<キー>}}` | デモの Vault にできたファイルの内容 |
| `{{v:<名前>}}` | 例に埋める名前・パス（`build.py` の `VALUES`。デモの定数から取る） |
| `{{example:final_report}}` | 最終報告の例。残した資料・件数は、採取した出力から作る |
| `{{seq:<名前>}}` | 順序図（SVG）。文言は `build.py` の `SEQUENCES` |
| `{{ver}}`・`{{commit}}`・`{{py}}` | プラグインの版・コミット・デモを実行した Python の版 |

### 直すときの決まり

- 写しを `page.html` に書かない。数・版・全文・出力は `{{名前}}` で埋める。
- デモの手順は、`build.py` の `scenario` に、SKILL.md・手順書の順に書く。手順書を変えたら、デモを合わせる。
- デモの入力は、最小の例にする。ブラウザ操作など実行できないもの（AskUserQuestion）は、書式から作った例だと、ページに書く。
- 出力に表示する `<D>` などは、HTML として解釈されて消える。生成の部品（`esc`）でエスケープする。`page.html` に直接書くときは `&lt;`・`&gt;` にする。
- 実ファイルの本文は、そのまま載せる。要約しない。
- 「書く」の例（AskUserQuestion・回答）に、デモの名前・パス・件数を手で写さない。`{{v:名前}}`・`{{example:…}}` で埋める。SKILL.md にしかない数値（再試行の回数など）は、写さず、「SKILL.md の手順N」と書く。
- 5 章（止まる条件）と 6 章（判断の規則）の表は、手で書いている。コードや SKILL.md を変えたら、見直す。
- フォント（Google Fonts）は、Artifact の規約で許された外部読み込みである。閲覧者の IP が Google に送られる。外すときは、`page.html` の `<link>` と `--font-*` を直す。
- 確かめていないことは、確かめていないとページに書く（「11 範囲と、確かめていないこと」）。

### 確認する

1. `python -m ruff check .`・`python -m ruff format --check .`・`python -m pytest` を通す。
2. `page.local.html` を、1200px 幅と 400px 幅で開く。横あふれは、プログラムで測る。ダークテーマは、ブラウザの配色を暗くして見る（`page.local.html` の枠は `color-scheme: light` だが、ページの配色は `prefers-color-scheme` に従う）。
3. Artifact に公開して、公開ページ実物を、ログイン済みの Chrome で開いて見る。
4. 直したら、再公開してから、もう一度見る。

### 公開した Artifact は連動しない

Artifact は、公開した時点の写しである。手順書・スクリプトを変えたら、再生成して再公開する。

### まだ載せていないもの

Obsidian・Claude Code の画面のスクリーンショットは、載せていない（撮る手段がなかった）。載せるときは、`docs/images/` に置き、撮影時のプラグインの版を、`build.py` の定数に持つ。
